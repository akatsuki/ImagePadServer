# ImagePadServer v1.8.0

ニコニコ動画のURLから、取得時点のコメントを焼き込んだ動画を作成できます。

- ニコニコURLを入力すると、URL欄の下に「ニコニココメントを焼き込む」トグルを表示します。初期値はオンで、オフにすると動画のみを取り込みます。
- コメント画像を再利用し、可逆圧縮・バッファ再利用・並行処理で焼き込み処理を高速化しました。Windows x64版には専用のWARP合成器を内蔵しています。
- コメントの移動は時刻を基準に計算し、元動画のフレームレートによって速度が変わらないようにしています。
- コメント付き動画の変換進捗を表示します。焼き込み完了後のHLS生成では映像を再エンコードしません。
- コメント取得・変換に失敗した場合はエラーを表示し、不完全な動画を公開しません。

今回のWindows版はCPU libx264の画質設定と1フレーム1スライスを維持しています。試験した非可逆パレット化や、合成・色変換のGPU移行は採用していません。Windows以外は既存のブラウザー描画経路を使用します。

AirPlayランタイムのバイナリ構成を維持し、ライセンス通知・完全な対応ソースをこのリリースの `ImagePadServer-AirPlay-Sources.zip` に揃えています。
