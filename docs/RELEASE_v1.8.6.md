# ImagePadServer v1.8.6

## 変更点

- 画像モードでX/Twitterの投稿URLを画像化できるようになりました。本文、ユーザー情報、日時、引用・リポスト、リンクカード、添付画像（最大4枚）、動画サムネイルを含めます。
- 投稿と画像の構成に合わせて4:3または3:4のレイアウトを選び、長辺2048pxで書き出します。
- react-tweetの取得コードを実行ファイルへ埋め込み、別途配布するreact-tweetフォルダーを不要にしました。投稿の取得にはNode.js 20以降が必要です。
- 投稿を囲む枠に、ライトモードでは黒、ダークモードでは白の柔らかな外影を追加しました。

## 配布物

Windowsランタイム、ライセンス通知、版固定の取得案内をアプリへ収録し、対応ソースを同じリリースの `ImagePadServer-AirPlay-Sources.zip` として配布します。ランタイムとソースの組はSHA-256、ライセンス在庫、H.264の1フレーム1スライス検査を通過しています。

X投稿の取得にはNode.js 20以降が必要です。Node.jsをPATHに追加するか、`IMAGEPAD_NODE` に実行ファイルを指定してください。
